# M1 walkthrough — repo skeleton

## What was built

M1 is the empty frame the other milestones hang on. There is a `uv` project with lint, type check and test tooling; one module holding every exception type; one module holding settings (model names, prices, budgets, paths); a Typer app that so far only knows `--home`, `-v` and `--version`; and the Pydantic models for the four things OBDient stores: a `Snapshot` of one scan, `Evidence` items the agent can cite, the `Report`, and the `Run` trace. Nothing talks to a car, a network or a model yet.

## How data flows

Nothing flows yet, so read this as the shape data will take:

```text
car -> Snapshot -> Evidence (E1, E2, ...) -> ReportDraft (model-written) -> Report (code-assembled)
                                                              every LLM / tool call -> Run
```

Read these three files first:

1. [src/obdient/schemas/common.py](../../src/obdient/schemas/common.py). The `Model` base makes every schema frozen and makes unknown fields an error. It also defines the string types reused everywhere (`DtcCode`, `PidId`, `EcuId`, `HexStr`) and `UtcDatetime`. Forty lines that explain every other schema's behaviour.
2. [src/obdient/schemas/report.py](../../src/obdient/schemas/report.py). The file is split in two by a comment: the **model-written part** (`ReportDraft` and what it contains) and the **code-written part** (`Report`). That split is the product's main safety idea: the model can only fill the draft; escalations, recalls, the disclaimer and the code list are added by code.
3. [src/obdient/config.py](../../src/obdient/config.py). `load_settings` is the only place model names, prices and budgets are defined.

## Decisions SPEC and PLAN did not dictate

| Decision | Alternative rejected |
| --- | --- |
| `ForbiddenReason` is defined in `errors.py`; `allowlist.py` re-exports it. | Defining it in `allowlist.py` as SPEC §4.2 shows. `ForbiddenCommandError` needs the enum, and `errors.py` must import nothing from the package. |
| `schemas/__init__.py` is empty. | Re-exporting the models from it. `config` imports `schemas.common` and `schemas.run` imports `config`, so re-exports make an import cycle. |
| `Budgets` and `ModelRole` stay in `config.py` (as SPEC says) even though `schemas/run.py` needs them. | Moving them to `schemas/common.py`. It would remove the cycle risk above but break "budgets only in `config.py`". |
| Identifier formats are enforced by the types (`DtcCode`, `PidId`, `EcuId`, `HexStr`), so a lowercase PID fails at construction. | Plain `str` fields with checks in the parsers. SPEC §0.4 states the formats but not where they are enforced. |
| `UtcDatetime` rejects naive datetimes and converts any offset to UTC. | Accepting naive values and assuming UTC. |
| `cached_input` prices equal `input` prices. | Guessing a discount. The real number is an open M0 item; this way logged cost can only be too high. |
| `load_settings(env=None)` reads the process environment and falls back to `.env` in the working directory; passing `env` skips both. | Calling `load_dotenv()`, which mutates `os.environ` and makes tests depend on your shell. |
| Pyright is `strict` for `src/` and `standard` for `tests/`. | Strict everywhere; test helpers that build models from `**dict` get noisy. |
| `pytest` excludes the three markers through `addopts`; passing `-m emulator` on the command line overrides it. | A `conftest.py` hook that skips marked tests. |
| Ruff ignores `RUF012` and excludes `*.md`. | See "Surprises". |
| `AdapterInfo` and `SinceClear` fields default to `None`. | Required fields, as SPEC's listing literally reads. §11 writes `SinceClear(...all None...)` as a default, so defaults are implied. |
| `.claude/settings.json` was edited but not committed. | Committing it. You had left `.claude/` out of both earlier commits. |

## One example, end to end

A reading of engine speed, as M2 will produce it:

```python
Reading(pid="010C", name="rpm", value=780.0, unit="rpm",
        ts=datetime(2026, 11, 12, 20, 30, tzinfo=timezone(timedelta(hours=2))),
        ecu="7E8", condition=Condition.IDLE, raw="0C30")
```

1. `pid` is checked against `^[0-9A-F]{4}$`. `"010c"` would raise `ValidationError`.
2. `ts` passes `AwareDatetime`, then `_to_utc` turns 20:30+02:00 into 18:30 UTC.
3. `raw` must be an even number of uppercase hex characters. `0C30` is the two data bytes; (0x0C·256 + 0x30)/4 = 780.
4. The object is frozen. `reading.value = 800` raises.
5. `model_dump_json()` writes `"ts":"2026-11-12T18:30:00Z"`. `test_datetimes_must_be_aware_and_serialize_as_utc_z` pins this.
6. Later (M4) three such readings become one `Evidence` item whose payload says `{"mean": {"value": 780, "unit": "rpm"}}`, and a claim in the report must cite its ID.

## Surprises and things to double-check

- **`.env.example` does not exist.** Your deny rule `Read(./.env.*)` also blocks me from creating it. Create it yourself with two lines: `OPENAI_API_KEY=` and `OBDIENT_HOME=`. I then added `Edit(./.env.*)` and `**/secrets*` rules to `.claude/settings.json` as PLAN said.
- **`ruff format .` rewrote SPEC.md.** Ruff 0.17 formats Python blocks inside Markdown, and it reflowed about 1,000 lines. I restored the file from git and excluded `*.md`. Check `git log -p SPEC.md` shows only the §5.4 note.
- **python-OBD is installed in the dev environment.** `ELM327-emulator` 4.0.0 depends on `obd` 0.7.3 (GPL). Nothing imports it, and it is not a runtime dependency, but PRD decision D1 says to keep away from it. Decide whether "installed transitively for tests" is acceptable.
- **`uv` was not installed.** `brew install uv` started compiling cmake from source on this Mac, so I stopped it and ran `pip install uv` under pyenv's 3.12.
- **The emulator pin is 4.0.0**, the only v4 release and the first to have `DTC_STORED` and `cmd_dtc_cleared`. The M0 raw-TCP spike was not done separately; M2's integration test covers it.
- Model IDs and prices in `config.py` are still the PRD's unverified values.

### Answers (spoilers)

1. `config.py` imports `schemas.common`, which runs `schemas/__init__.py`; that would import `schemas.run`, which imports `config` while it is still half-loaded.
2. Models are frozen, so assignment raises, and the list itself should not be mutated. Build a new object with `snapshot.model_copy(update={...})`; snapshots are meant to be immutable after capture.
3. Only what comes from `ReportDraft`: `findings`, `ruled_out`, `complaint_patterns` (text and citations), `questions_for_mechanic`, `next_steps`. Everything else is filled by code.
4. `/tmp/a`; the argument beats the variable. No: the key is only required when an LLM call is attempted.
5. A `-m` given on the command line comes after the one in `addopts`, and the last `-m` wins.
